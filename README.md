# RF/Microwave Calculator

A free, offline-capable calculator suite for RF and microwave design work, made by **TunaBoy**.

**Open it here:** https://tunaackgz.github.io/rf-calc/

## What it does

**Conversions**
- dB / dBm Calculator: gain ratios, dBm, W, dBV, voltage and current
- VSWR Calculator: VSWR, return loss, |Γ|, mismatch loss, power split
- Reflection ↔ Impedance: Γ to R + jX and back
- Wavelength: λ, λ/2, λ/4 from frequency or period
- Unit Converter: mil, inch, µm, mm, cm, m and copper weight

**Circuit design**
- Transmission Line: microstrip, CPWG and stripline (W ↔ Z₀, εeff, λg)
- L-Network Matching, Attenuator Pad (Pi / T), LC Resonance
- Reactance, RC / RL Filter, Resistor Divider, Parallel Resistors

**System and receiver**
- Cascade Analysis, PA Efficiency, MDS Calculator
- Free Space Path Loss, ADC Calculator with Nyquist zone ruler

## Use it on your phone or offline

- **iPhone:** open the link in Safari, tap Share, then *Add to Home Screen*.
- **Android / desktop Chrome or Edge:** open the link and choose *Install app*.
- **Offline PC:** the app is a single HTML file and needs no internet connection.
